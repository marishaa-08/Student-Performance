# Student Performance

## Project Overview

The Student Performance project is a Python-based application that analyzes student academic performance using Pandas and NumPy.

## Objective

The objective is to analyze student marks, calculate total and average marks, assign grades, identify pass/fail results, and study performance patterns.

## Technologies Used

* Python
* Pandas
* NumPy
* CSV dataset
* Visual Studio Code

## Dataset

The project uses `students.csv`, containing data for 20 fictional students, including:

* Student ID and name
* Department
* Python, Mathematics, and Computer Fundamentals marks
* Attendance
* Weekly study hours
* Assignments completed
* Lab performance

## Features

* Loads and validates student data
* Calculates total and average marks
* Assigns grades and pass/fail results
* Displays class performance statistics
* Performs subject-wise analysis
* Identifies the top three performers
* Analyzes study hours, attendance, assignments, and lab performance
* Exports results to `student_analysis_results.csv`

## How to Run

1. Install Python.

2. Install the required libraries:

   `python -m pip install pandas numpy`

3. Keep `main.py` and `students.csv` in the same folder.

4. Run the application:

   `python main.py`

## Expected Output

The application displays student results, class performance statistics, subject-wise analysis, top performers, and learning-pattern analysis in the terminal.

It also generates `student_analysis_results.csv`.

## Learning Outcomes

This project provides practice with Python functions, loops, NumPy calculations, Pandas DataFrames, CSV files, data validation, and basic data analysis.
